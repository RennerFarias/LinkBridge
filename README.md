# LinkBridge

Encurtador de URLs simples e pessoal, focado em privacidade e agilidade.

## Proposta

Serviços públicos de encurtamento frequentemente monetizam cliques, rastreiam usuários ou impõem limites artificiais. O **LinkBridge** foi criado para ser direto:

- **Privacidade:** você mantém o controle dos seus links.
- **Simplicidade:** encurtamento rápido e redirecionamento HTTP direto.
- **Zero custo de manutenção:** arquitetura serverless rápida e gratuita.
